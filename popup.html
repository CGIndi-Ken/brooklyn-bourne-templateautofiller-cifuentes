Bulk template creation

Set shared settings above (category, pricing, vendor, brand, measurements, inventory), then paste one full product name per line. Each name becomes a template and its product Name. Existing names are skipped.

Optional: paste three columns from a spreadsheet: Name, Strain, Description (tab-separated). Strain and description are blank unless supplied per row. External ID is left blank. All other settings above are shared, including THC.

Move the exported JSON file to another computer and import it there. Matching names are imported as separate copies.

Location details tab

Copies base price, cost, external category, low stock threshold and external ID from this template. Available on POS and Available online are always set to Yes there, whether or not this is ticked.

To fill several product tabs in a row, use "Fill every tab" in the on-page panel or press Alt+Shift+Z.
Blank fields are skipped. Type and Default unit are always Quantity. Sync to METRC is always Yes, and SKU generation runs when the SKU is empty.
Online details is filled last: Name is copied into Online title, followed by your saved Online description.
