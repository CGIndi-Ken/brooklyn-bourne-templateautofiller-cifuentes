Bulk template creation

Paste one product name per line. Existing names are skipped.

Spreadsheet format

Name, Strain, Description — tab-separated, with an optional header. Quoted multiline descriptions are supported. Cost and price start blank; grams can come from the product name. Other shared settings carry over.

About backups

Export saved templates and pairings as JSON. Import restores them; matching names become separate copies. Save drafts first.

Location details tab
What gets copied?

Price, cost, external category, stock threshold and external ID. POS and online availability are always Yes.
